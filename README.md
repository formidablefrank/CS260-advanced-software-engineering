# Advanced Software Engineering (CS260)

This repository contains coursework demonstrating advanced software engineering principles, practices, and methodologies. The materials cover software quality assurance, defect analysis, metrics-driven development, and real-world software failure analysis from a graduate-level computer science program (2015-2016).

## Overview

The course emphasizes evidence-based software development practices through the application of quantitative metrics, quality models, and empirical analysis of software systems. Students analyze real-world software failures, develop measurement and estimation frameworks, and apply quality assurance techniques to complex software projects.

## Technical Skills

The coursework develops proficiency in:

- Software metrics and quantitative analysis (KLOC, Function Points, cyclomatic complexity)
- Defect analysis and removal efficiency (DRE) measurement
- Software quality models (FURPS+, Six Sigma)
- Operational profiling and usage-based testing
- Software project planning and risk management
- Test coverage analysis and code instrumentation
- Design metrics (coupling, cohesion, complexity)

## Coding Exercises and Problem Sets

The repository includes hands-on exercises addressing:

- **Defect Metrics Analysis**: Homework assignments on calculating defect removal efficiency and analyzing defect patterns
- **Software Quality Assessment**: Problem sets covering quality metrics, complexity analysis, and estimation techniques
- **Operational Profile Development**: Exercises in creating operational profiles, usage scenarios, and test case derivation
- **Project Deliverables**: Comprehensive technical reports demonstrating project planning, risk assessment, and test strategy development

## Learning Objectives

After completing these materials, students understand:

- How to quantify software quality using established metrics and measurement frameworks
- The relationship between process metrics and product quality
- How to identify and analyze design defects through coupling and cohesion measures
- The application of quality models to requirements classification and verification
- How to estimate software size and effort using industry-standard techniques
- How to develop test strategies based on operational profiles and usage patterns
- The critical importance of quality in safety-critical systems through analysis of real-world failures

## Case Studies

The repository includes detailed analysis of three significant software system failures:

- **Ariane 5 Rocket Failure** (1996): Demonstrates consequences of inadequate software reuse analysis and integer overflow handling in real-time systems
- **London Ambulance Service System Failure** (1992): Illustrates risks of inadequate testing, process management, and operational readiness assessment
- **Therac-25 Radiotherapy System Failure** (1985-1987): Shows dangers of insufficient safety analysis and overconfidence in software-only safety mechanisms

These cases provide empirical evidence of the costs associated with poor software engineering practices.
